Validation

Validation types

Section titled “Validation types”

The value of type in a ValidationOption:

type Checks
required The field is not empty
email E-mail address format
number Numeric
code Numeric or -, +, *
hiragana Hiragana
katakana Katakana
kana Hiragana or katakana
hankaku-kana Half-width katakana
alpha Half-width alphabetic characters
alphanumeric Half-width alphanumeric characters
zen-alpha Full-width alphabetic characters
zen-alphanumeric Full-width alphanumeric characters
['equal', 'field_name'] The value equals another field
'custom' Your own function (validate)

validation accepts an array and evaluates the entries in order. A single option can be passed without an array.

Constraints

Section titled “Constraints”

ValidationOption can also carry constraints. They are skipped for empty values, so combine them with required when the field is mandatory.

Option Type Description
min / max number Numeric range
minlength / maxlength number String length
pattern string | RegExp Regular expression the value matches

Constraints are evaluated together with type; omit type when you only need constraints. The failing constraint name (min, max, minlength, maxlength, pattern) is used for the messages lookup.

Custom validators

Section titled “Custom validators”

Use type: 'custom' with a validate function. Return true (or nothing) when the value is valid, false to use the configured message, or a string to use it as the error message.

The function receives (value, { formEl, values, field }) and runs for each element that shares the field name.

Async validators

Section titled “Async validators”

Set async: true to run a validator only from validateAsync() and form submission. Async validators are skipped while typing.

Submitting a form with async validators is prevented until they resolve. When on_submit is not configured, the form is submitted natively after a successful validation.

Cross-field rules

Section titled “Cross-field rules”

with lists the related fields and mode controls how they are combined.

mode Behavior
or Valid when at least one of the fields (including itself) is filled
and Valid when all fields (including itself) are filled (default)
