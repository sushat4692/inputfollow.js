## Validation types

The value of `type` in a `ValidationOption`:

| `type`                        | Checks                                        |
| ----------------------------- | --------------------------------------------- |
| `required`                    | The field is not empty                        |
| `email`                       | E-mail address format                         |
| `number`                      | Numeric                                       |
| `code`                        | Numeric or `-`, `+`, `*`                      |
| `hiragana`                    | Hiragana                                      |
| `katakana`                    | Katakana                                      |
| `kana`                        | Hiragana or katakana                          |
| `hankaku-kana`                | Half-width katakana                           |
| `alpha`                       | Half-width alphabetic characters              |
| `alphanumeric`                | Half-width alphanumeric characters            |
| `zen-alpha`                   | Full-width alphabetic characters              |
| `zen-alphanumeric`            | Full-width alphanumeric characters            |
| `['equal', 'field_name']`     | The value equals another field                |
| `'custom'`                    | Your own function (`validate`)                |

`validation` accepts an array and evaluates the entries in order. A single
option can be passed without an array.

### Default messages

`message` is optional. When it is omitted, the value of the `messages` option
keyed by the validation type is used.

```js
InputFollow('#form', {
    messages: { required: 'This field is required' },
    rules: [{ name: 'name', validation: [{ type: 'required' }] }],
})
```

## Custom validators

Use `type: 'custom'` with a `validate` function. Return `true` (or nothing)
when the value is valid, `false` to use the configured message, or a string to
use it as the error message.

```js
{
    name: 'username',
    validation: [
        {
            type: 'custom',
            message: 'This username is reserved',
            validate: (value) => value !== 'admin',
        },
    ],
}
```

The function receives `(value, { formEl, values, field })` and runs for each
element that shares the field name.

<LiveDemo

    params={{

            {

        ],

        <input

            name="v-custom-user"
            type="text"
            placeholder="Try &quot;admin&quot;"
        />
    </div>
</LiveDemo>

## Cross-field rules

`with` lists the related fields and `mode` controls how they are combined.

| `mode` | Behavior                                                           |
| ------ | ------------------------------------------------------------------ |
| `or`   | Valid when at least one of the fields (including itself) is filled |
| `and`  | Valid when all fields (including itself) are filled (default)      |

### Either field is required (`mode: 'or'`)

<LiveDemo
    title={'mode: "or"'}
    params={{
        rules: [
            {
                name: 'v-or-phone',
                validation: [
                    {
                        type: 'required',
                        message: 'Phone or E-mail is required',
                        mode: 'or',
                        with: { 'v-or-mail': 'required' },
                    },
                ],
            },
        ],
    }}
>
    <div class="live-demo__field">
        <label for="v-or-phone">Phone</label>
        <input id="v-or-phone" name="v-or-phone" type="tel" />
    </div>
    <div class="live-demo__field">
        <label for="v-or-mail">E-mail</label>
        <input id="v-or-mail" name="v-or-mail" type="email" />
    </div>
</LiveDemo>

## Conditional validation

`if` makes a rule depend on other fields. `target` maps a field name to the
value it should have.

```js
{
    name: 'if_target',
    validation: [
        {
            type: 'required',
            message: 'If this is checked, the text field is required',
            if: {
                mode: 'and',
                target: { if_from: true },
            },
        },
    ],
}
```

<LiveDemo

    params={{

            {

                validation: [

                            mode: 'and',
                            target: { 'v-if-check': true },

            },
        ],
    }}
>
    <div class="live-demo__field live-demo__field--inline">
        <input id="v-if-check" name="v-if-check" type="checkbox" />
        <label for="v-if-check">I have a company</label>
    </div>
    <div class="live-demo__field">
        <label for="v-if-text">Company name</label>
        <input id="v-if-text" name="v-if-text" type="text" />
    </div>
</LiveDemo>

## Equality

`['equal', 'field_name']` validates that two fields have the same value, which
is useful for password confirmation.

<LiveDemo
    title="equal"
    params={{
        rules: [
            {
                name: 'v-eq-confirm',
                validation: [
                    {
                        type: ['equal', 'v-eq-password'],
                        message: 'The values must be the same',
                    },
                ],
            },
        ],
    }}
>
    <div class="live-demo__field">
        <label for="v-eq-password">Password</label>
        <input id="v-eq-password" name="v-eq-password" type="password" />
    </div>
    <div class="live-demo__field">
        <label for="v-eq-confirm">Confirm password</label>
        <input id="v-eq-confirm" name="v-eq-confirm" type="password" />
    </div>
</LiveDemo>
