`inputfollow.js` is a small TypeScript library that adds validation and input
limiting to an existing `<form>`. Describe your fields once, and it takes care
of validating, rendering error messages and blocking invalid submissions.

<CardGrid>
    <Card title="Validation" icon="approve-check-circle">
        Required, e-mail, number, code, kana, alphanumeric and equality checks —
        combine them freely per field.
    </Card>
    <Card title="Input limiting" icon="pencil">
        Convert field values to the allowed characters on validation
        (`number` and `code` limits).
    </Card>
    <Card title="Cross-field rules" icon="random">
        Use `with` / `mode` for “at least one of” or “all of”, and `if` for
        conditional validation.
    </Card>
    <Card title="TypeScript" icon="seti:typescript">
        Ships with type definitions and TSDoc. Available as ESM and UMD builds.
    </Card>
</CardGrid>

## Quick start

```bash
npm install inputfollow.js
```

```js
import { InputFollow } from 'inputfollow.js'

InputFollow('#form', {
    rules: [
        {
            name: 'email',
            validation: [
                { type: 'required', message: 'E-mail is required' },
                { type: 'email', message: 'E-mail is not Email format' },
            ],
        },
    ],
})
```

Continue with [Getting Started](./guides/getting-started/) to learn about
installation options and the returned API.
