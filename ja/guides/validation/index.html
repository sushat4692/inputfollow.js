バリデーション

バリデーション種別

Section titled “バリデーション種別”

ValidationOption の type に指定できる値です。

type 内容
required 必須入力
email メールアドレス形式
number 数値
code 数値または - + *
hiragana ひらがな
katakana カタカナ
kana ひらがなまたはカタカナ
hankaku-kana 半角カタカナ
alpha 半角英字
alphanumeric 半角英数字
zen-alpha 全角英字
zen-alphanumeric 全角英数字
['equal', 'field_name'] 指定フィールドと値が一致するか
'custom' 独自の関数（validate）

validation は配列で複数指定でき、上から順に評価されます。 1つだけの場合は配列にせず直接指定することもできます。

制約（constraints）

Section titled “制約（constraints）”

ValidationOption には制約も指定できます。空の値ではスキップされるため、必須にする場合は required と併用してください。

オプション 型 内容
min / max number 数値の範囲
minlength / maxlength number 文字列の長さ
pattern string | RegExp 値が一致すべき正規表現

制約は type と同時に評価されます。制約だけを使う場合は type を省略できます。 失敗した制約名（min / max / minlength / maxlength / pattern）が messages の参照キーになります。

カスタムバリデータ

Section titled “カスタムバリデータ”

type: 'custom' と validate 関数で独自の検証を書けます。 値が正しければ true（または何も返さない）、不正なら false（設定したメッセージを使用）か、 エラーメッセージ文字列を返します。

関数は (value, { formEl, values, field }) を受け取り、同名の要素それぞれについて実行されます。

非同期バリデーション

Section titled “非同期バリデーション”

async: true を付けると、validateAsync() とフォーム送信時だけ実行されます。 入力中はスキップされます。

非同期バリデータがあるフォームの送信は、検証が終わるまで保留されます。 on_submit が未指定の場合は、検証成功後にネイティブの送信を実行します。

複数フィールドの連携

Section titled “複数フィールドの連携”

with に関連フィールド、mode に評価方法を指定します。

mode 動作
or with のいずれか1つ（または自身）が満たされれば OK
and with のすべて（および自身）が満たされれば OK（デフォルト）
